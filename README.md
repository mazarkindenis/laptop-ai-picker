# Laptop AI Picker

Минимальное одностраничное веб-приложение на Next.js, TypeScript и Tailwind CSS для подбора ноутбуков по текстовому запросу. Сейчас в интерфейсе используются моковые данные, без авторизации, базы данных и внешнего API.

## Что есть в MVP

- hero-блок с заголовком и подзаголовком;
- большое текстовое поле для ввода пользовательского запроса;
- кнопка `Подобрать`;
- блок результатов с кратким описанием запроса, рекомендациями и карточками ноутбуков;
- адаптивный минималистичный интерфейс для мобильных устройств и десктопа.

## Стек

- Next.js
- TypeScript
- Tailwind CSS

## Запуск проекта

### 1. Установить зависимости

```bash
npm install
```

### 2. Запустить dev-сервер

```bash
npm run dev
```

После запуска приложение будет доступно по адресу `http://localhost:3000`.

## Полезные команды

```bash
npm run build
npm run start
npm run lint
```
